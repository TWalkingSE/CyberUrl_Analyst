## Practical Release Checklist

Before publishing the executable, confirm that the release artifact contains:

- `LICENSE`
- `THIRD_PARTY_NOTICES.md`
- `GPL-3.0.txt`
- the executable files produced by `build.py`
- access to the corresponding source code for the distributed build
