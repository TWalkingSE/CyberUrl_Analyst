# CyberUrl_Analyst
**Ferramenta educacional de análise de URLs e domínios maliciosos.**  Desenvolvida em Python com Streamlit, o CyberURL Analyst detecta, analisa e **ensina** usuários a identificar ameaças em URLs e domínios. O objetivo não é apenas mostrar *o quê* é perigoso, mas explicar *por quê* — formando pessoas que sabem se proteger sozinhas.
